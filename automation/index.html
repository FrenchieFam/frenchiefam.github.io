What would a live version need? +

THE EVIDENCE

A small prototype.
Clear boundaries.

One decision function is embedded in the offline page and exported workflow. That keeps the examples consistent.

What was tested

Unanswered and busy calls; completed/failed outcomes; anonymous callers; missing inputs; assumed opt-out, permission and duplicate state. Local tests also check sender, recipient and the proposed duplicate key.

What the export does

Manual Trigger → Fictional call event → Draft only. The generated JavaScript was exercised in Node with 16 scenarios. The JSON is inactive, contains no credentials and has no webhook or SMS node.

What remains open

Import and execution in a running n8n instance, provider webhooks, durable duplicate handling, actual permission/opt-outs, delivery and monitoring. A voicemail may count as a completed dial attempt.

No customer deployments, client revenue, recovered leads or delivery results are claimed.
