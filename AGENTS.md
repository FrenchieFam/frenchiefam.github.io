# FrenchieFam portfolio

Buildless HTML/CSS/JavaScript site, published by GitHub Pages from main/root.
Keep CNAME=frenchiefam.dev and existing routes. No build framework or external
runtime dependency is needed. Homepage uses home.css/home.js; the Chromebook
case study lives under chromebook-workbench/ and has its own CSS/JS.

Preserve truthful labels: missed-call demo is a simulation, sends no messages,
and has no connected provider. The workbench bug explainer is also a local
illustration. Never invent customers, income, deployment results or test claims.
Technical device claims must match the public repositories' validation records.

For changed JavaScript, run node --check on the changed files. Check local
assets, anchors and duplicate IDs. For layout/interactive changes, use an existing
owner-authorized browser connection and inspect desktop/mobile behavior; reset
viewport and restore the test tab afterward. Honor Disconnect and explicit stops.
Do not imply a laptop was tested when it was asleep/unreachable.

Do not publish pairing configs, account screenshots, private handoffs, device
endpoints or credentials. New dependencies/accounts/listeners should solve an
actual requirement. Keep source and generated previews separate. Recording
preparation is a separate user task, not part of portfolio maintenance.
